操作手冊與常見問題

找不到符合的說明項目，請嘗試其他關鍵字。
一、入門與帳號設定
1. 如何建立新帳本或邀請朋友加入？
點擊頂部 「建立」 輸入帳本名稱即可開帳並成為該帳本的 帳本管理者。帳本進行中時，所有成員都可以在主卡片下方看到 6 碼邀請碼，點擊 「邀請朋友」 即可複製專屬連結或透過 LINE 好友選單傳送；朋友點擊連結或輸入邀請碼即可加入。
2. 受邀加入時跳出「認領代管成員」該怎麼選？
若帳本管理者先前已幫你建立「未綁定 LINE」的代管名單，受邀加入時系統會先詢問身分：
• 名單中有你：點擊對應名字並二次確認後，原本幫你代記的墊付與均攤紀錄會自動合併至你的 LINE 帳號（合併後無法還原）。
• 名單中沒有你或不確定：請直接點選 「我是新成員，直接加入」。
3. 為什麼建議加入記帳本官方帳號好友？
未加好友仍可正常開啟網頁記帳；但加入官方帳號好友後，才能在正式結算、被加入新帳本或接任帳本管理者時收到 LINE 推播通知，也能直接在 LINE 聊天室輸入文字快速記帳、帶入定期支出與查詢個人明細。
二、日常記帳、贊助／補助款與定期支出
4. 朋友沒用 LINE 或不想自己操作記帳怎麼辦？
帳本管理者可點擊主卡片下方的 「代管成員」，輸入暱稱（例如：阿公、不記帳的小美）建立 未綁定 成員。代管成員一樣可作為墊付人、補助提供人或均攤／受惠對象參與結算，日後對方若加入帳本也能隨時認領合併。
5. 記錯金額或分攤名單可以修改嗎？
只要帳本狀態為 「進行中」，所有成員皆可至 「帳務明細」 分頁點擊項目右側的 「編輯」 修改類型、名稱、金額、墊付／提供人或分攤名單，也可刪除該筆項目。一旦帳本管理者執行「正式結算」後，帳本即鎖定為唯讀。
6. 如何修改成員在帳本內的顯示暱稱？
點擊主卡片上「我的暱稱」旁的 「改名」，即可設定專屬於目前帳本的顯示名稱；帳本管理者則可在 「結算總覽」 的成員統計表中，點擊任一位成員（包含代管成員）旁的鉛筆圖示協助修改暱稱。
7. 什麼時候使用「贊助／補助款」？金額怎麼計算？
適合「有人領取補助款或自掏腰包贊助大家花費」（如旅遊補助、長輩贊助金、刷卡回饋）的情境。點擊「新增帳務項目」後，將頂部類型切換為 「🎁 贊助／補助款」 即可輸入：
• 情境 1（平分外部補助）：A 領取 $3,000 旅遊補助，受惠成員勾選 A、B、C 三人 ➔ 每人各折抵 $1,000；A 負責拿出 $3,000 扣掉自己折抵的 $1,000，補助淨額為 -$2,000，B 與 C 各為 +$1,000。
• 情境 2（個人純贊助他人）：A 自掏腰包贊助 $3,000，受惠成員取消勾選 A、只勾 B、C ➔ A 補助淨額為 -$3,000，B 與 C 各折抵 +$1,500。
• 帳本含贊助／補助款時，「結算總覽」會自動展開 「贊助／補助」 欄位，讓 已預付 - 應均攤 + 贊助／補助 = 淨額 清楚透明。
8. 如何使用「個人定期支出」提醒每月固定開銷？
定期支出範本綁定你的個人 LINE 帳號，跨所有帳本皆可共用（適合每月固定訂閱費、會員費）：
• 建立與管理：可從 「我的明細 ➔ 定期支出設定」 新增，或在新增一般支出時勾選 「同時儲存為我的定期支出範本」。金額可填 0 代表浮動帳單（如水電費），也可設定每月扣款日（1～31 號）。
• 均攤記憶與待入帳提醒：範本僅記憶已綁定 LINE 的成員以確保跨帳本精準對應（未綁定代管成員可於帶入時再手動勾選）；系統會自動比對目前帳本，尚未入帳的項目會在帳務頁頂部提示。
三、LINE 聊天室快速記帳
9. 怎麼在 LINE 聊天室直接打字快速記帳？
• 自由輸入：在聊天室直接輸入 項目 金額（例如：晚餐 600）。（註：聊天室快記以一般支出為主，贊助／補助款請開啟網頁切換類型輸入。）
• 定期支出帶入：輸入 定期（或點擊快捷列「定期支出」）可查看個人定期清單與待入帳狀態，點擊固定金額項目即可直接產生草稿。
• 草稿防呆：系統會先回傳 「草稿確認卡」 讓你核對目標帳本與金額，按下 「✅ 確認入帳」 才會正式儲存。
10. 聊天室記帳如何指定帳本、墊付與均攤？編號去哪看？
完整格式為 #帳本編號 項目 金額 @墊付編號 /均攤編號（例如：#2 晚餐 600 @3 /1 2，符號皆可省略）：
• 智慧預設：省略 # 預設寫入目前預設帳本（寫在開頭或句尾皆可）；省略 @ 預設由你墊付；省略 / 預設全員均攤。
• 查詢編號：點擊聊天室快捷列的 「帳本與成員編號」（或輸入 編號）即可一次查看所有進行中帳本與各帳本成員的對應編號；點擊 「快速記帳說明」 則可查看詳細指令與範例。
• 多筆輸入：支援換行一次輸入多筆花費（最多 15 筆），可於第一行單獨輸入 #2 指定整批寫入同一本帳本。
11. 電腦版 LINE 看不到下方圖文選單怎麼辦？
LINE 電腦版原生不支援顯示下方圖文選單，只要在聊天室輸入 選單 或 ?，機器人就會回傳功能按鈕卡片並在輸入框上方重新喚出快捷按鈕列。
四、結算、報表與管理者權限
12. 「最小轉帳結清路徑」是怎麼計算的？
系統會統計每位成員「已預付」減去「應均攤」，再加上「贊助／補助款」後的最終淨額（正數為應收、負數為應付），再透過演算法自動配對付款人與收款人，以最少的轉帳次數讓全員帳目歸零結清。
13. 如何正式結算鎖定並保存帳務報表？
• 正式結算：帳本管理者可在 「結算總覽」 點擊「正式結算並鎖定帳本」，鎖定後全員變為唯讀，並可自由選擇是否同時 LINE 推播通知大家。
• 保存與分享：所有成員隨時都可在「結算總覽」點擊 「複製文字」 貼到 LINE 群組，或點 「匯出 CSV」 下載 Excel 檔案保存（若於 LINE 內建視窗操作，點擊「外部開啟匯出」即可切換至外部瀏覽器下載）。
14. 如何沿用固定成員、移交管理權限或刪除帳本？
• 沿用固定成員：點擊頂部「建立」新帳本時，勾選 「直接加入目前帳本的成員」，即可一鍵帶入原成員（沿用暱稱）並自動推播通知大家。
• 移交管理權限：帳本管理者可至 「結算總覽」 指定另一位已綁定 LINE 的成員接替作為帳本管理者，移交後系統會推播通知接任者。
• 刪除帳本：僅帳本管理者可至 「結算總覽」 最下方點擊「刪除此記帳本」，完整輸入帳本名稱確認後即可永久清除所有資料。
